# Project 2: Exploratory Data Analysis (EDA) - E-Commerce Intelligence

## 📌 Project Overview
This project serves as the discovery phase for our data analytics internship at DecodeLabs. Building upon our cleaned dataset from Project 1, this phase focuses on statistical analysis, outlier detection, relationship mapping, and translating raw data into business insights.

## 🛠️ Tools & Libraries Used
- Python, Pandas, NumPy (Data manipulation & statistical metrics)
- Matplotlib, Seaborn (Professional data visualization)

## 📊 Key Findings & Insights
- **Revenue Scale:** Successfully tracked **$1,264,761.96** across 1,200 orders.
- **Central Tendency:** Identified right-skewness in transaction values, noting a Mean of **$1,053.97** versus a Median of **$823.62**. The median is established as the baseline for robust customer behavior analysis.
- **Top Product:** The **Chair** category emerged as the top revenue driver (**$195,620.11**).
- **Data Forensics:** Applied the IQR method to isolate high-value outliers, distinguishing data entry noise from true business signals (VIP/bulk purchases).

## 🚀 How to Run
1. Ensure Python 3.x and required libraries (`pandas`, `numpy`, `matplotlib`, `seaborn`) are installed.
2. Place `Cleaned_Dataset_Project1.csv` in the same directory.
3. Run the Jupyter Notebook `Project2.ipynb`.
